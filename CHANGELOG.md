# Changelog

All notable changes to **ReqFlow: Simple API Tester** are documented here.

## 0.3.0

- **cURL:** Copy as cURL from the request panel; import from cURL via command and Collections toolbar.
- **Environments:** Dedicated Environments sidebar, variable editor panel, set active environment from the tree.
- **Status bar:** Active environment picker and sending indicator.
- **Commands:** Reveal storage folder, open pinned request tabs, focus URL bar.
- Documentation and Marketplace publishing instructions in README.

## 0.2.0

- Request builder: query params, headers (bulk paste, auto headers), body (JSON with CodeMirror, form, raw), Bearer/Basic auth.
- Collections persisted in VS Code global storage; tree context menus (rename, delete, duplicate, folders).
- History (last 50 sends) and status bar environment switcher with `{{variable}}` resolution.

## 0.1.0

- Initial preview: send HTTP requests from a webview, view status/time/size and response body/headers.
- Sidebar placeholders for collections and history.
